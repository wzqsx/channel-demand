# 渠道要货

临时前端工具：渠道要货、库存导入、销货核对、缺货与预警（按公司主体隔离）。

- 技术栈：Vue 3 · TypeScript · Vite · Pinia · Element Plus
- 数据：浏览器本地持久化（无后端）

## 快速开始

```bash
npm install
npm run dev
```

更多说明见 [使用说明.md](./使用说明.md)。

## 脚本

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 本地开发 |
| `npm run build` | 类型检查 + 构建 |
| `npm run selfcheck` | 主数据与主体隔离逻辑自检 |
| `npm run preview` | 预览构建产物 |
